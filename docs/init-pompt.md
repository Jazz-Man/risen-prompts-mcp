Використовуючи serena MCP утиліти повністю проаналізую цей Python сорс код в папці tmp/mcp-prompt-optimizer разом з всією доступною документацією в файлі tmp/mcp-prompt-optimizer/README.md для розуміння що це за проект і як його використовувати. Все потрібно зробити максимально детально:
- проаналізуй функціонал
- проаналізуй приклади коду якщо вони там є


В цілому цей проект це "MCP Prompt Optimizer", він написаний на Python, але я хочу його повністю переписати на typescript з використанням Effect TS libraries, а саме пакету "@effect/ai" в якому є можливість створювати McpServer. Ця ідея виникла тому що я не є Python розробником.
В кінці я хочу отримати наступне: 
- структурований та максимально детальний опис бізнес логіки без привязки до мови програмування
- структурований та максимально детальний опис архітектури без привязки до мови програмування, можеш використовувати псевдопрограмування
- також потрібно в цей бізнес план включити всі описані в Python коді шаблони промптів які там викорисовуються
